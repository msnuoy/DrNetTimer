# DrNetTimer ⏳

ربات Inline تلگرام برای شمارش معکوس زنده داخل خود پیام، روی یک Cloudflare Worker.
بدون دیتابیس خارجی و بدون VPS.

```
@DrNetTimerBot 3d 🚀 نسخه جدید Dr.Net
```

</div>

## نحوهٔ کار

```
Telegram ──webhook──▶ Worker
  inline_query          → پاسخ فوری داخل همان پاسخ webhook (بدون loading)
  chosen_inline_result  → inline_message_id → Durable Object «Countdown»
  callback_query        → نمایش زمان دقیق تا ثانیه (بدون state)
Countdown (یک DO برای هر پیام) ── alarm هر دقیقه ──▶ editMessageText
```

- زمان هدف داخل `result_id` و `callback_data` ذخیره می‌شود، پس Worker هیچ state‌ای ندارد.
- پیام فقط هفته، روز، ساعت و دقیقه را نشان می‌دهد. واحدهای خالیِ ابتدا نمایش داده نمی‌شوند؛ مثلاً ۵ روز
  «هفته» ندارد و زیر یک ساعت فقط «دقیقه» می‌ماند. دقیقه رو به بالا گرد می‌شود، پس تا لحظهٔ آخر «۰۱ دقیقه» است.
- هر پیام ارسال‌شده یک Durable Object کوچک (SQLite، روی پلن رایگان هم هست) دارد.
  این DO با alarm پیام را ویرایش می‌کند و بعد از پایان زمان خودش پاک می‌شود.
- پیام دقیقه‌ای یک بار ویرایش می‌شود، درست همان لحظه‌ای که دقیقه عوض می‌شود.
- اگر تلگرام خطای 429 بدهد، ربات به اندازهٔ `retry_after` صبر می‌کند و ادامه می‌دهد.
  اگر پیام پاک شود، شمارش متوقف می‌شود.

## راه‌اندازی (حدود ۵ دقیقه)

**۱. در تلگرام، [@BotFather](https://t.me/BotFather):**
- `/newbot`: یک نام و یک username بدهید و توکن را کپی کنید. username باید به `bot` ختم شود (مثلاً `DrNetTimerBot`).
- `/setinline`: ربات را انتخاب کنید و یک placeholder بدهید، مثلاً `3d عنوان`.
- `/setinlinefeedback`: ربات را انتخاب کنید و **Enabled** را بزنید. **ضروری است**، وگرنه پیام زنده نمی‌شود.

**۲. روی کامپیوتر خودتان** (Node.js نسخهٔ ۲۲ یا بالاتر، و یک حساب رایگان Cloudflare):

```bash
cd DrNetTimer
npm run setup
```

اسکریپت این کارها را خودش انجام می‌دهد:
- توکن را می‌پرسد، به‌علاوهٔ شناسهٔ کاربرانی که اجازهٔ ساخت شمارش دارند (اختیاری).
- اگر لازم باشد، مرورگر را برای ورود به Cloudflare باز می‌کند.
- Worker را deploy می‌کند و secretها را ذخیره می‌کند.
- webhook را ثبت می‌کند، دستور `/start` و توضیح ربات را تنظیم می‌کند و روشن بودن Inline Mode را چک می‌کند.

**۳. تست:** به ربات `/start` بدهید. راهنما و شناسهٔ عددی شما را برمی‌گرداند. بعد در هر چتی بنویسید `@DrNetTimerBot 2m تست` و نتیجه را بفرستید. با عوض شدن هر دقیقه، شمارش یکی کم می‌شود.

**خصوصی کردن ربات:**
- شناسهٔ عددی را از جواب `/start` بردارید و بزنید (در ویندوز `npx.cmd`):
  `echo 123456789 | npx wrangler secret put ALLOWED_USERS`. چند شناسه را با کاما جدا کنید.
- `/start` نشان می‌دهد که شما اجازهٔ ساخت شمارش دارید یا نه.
- برای عمومی کردن دوباره: `npx wrangler secret delete ALLOWED_USERS`.

### اگر کار نکرد

| مشکل | علت |
|---|---|
| با تایپ `@bot` نتیجه‌ای نمی‌آید | `/setinline` انجام نشده یا webhook ثبت نشده. `npm run setup` را دوباره اجرا کنید. |
| پیام ارسال می‌شود ولی کم نمی‌شود | `/setinlinefeedback` روی Enabled نیست. |
| اسکریپت به آدرس Worker نمی‌رسد | لینکی را که چاپ می‌کند در مرورگر باز کنید (شاید با VPN). |

لاگ زنده: `npm run logs`

## فرمت ورودی

| نوع | مثال |
|---|---|
| مدت (`w d h m s`) | `3d` · `2h30m` · `1w2d` · `90s` |
| ساعت (امروز، یا فردا اگر گذشته باشد) | `18:30` |
| تاریخ شمسی یا میلادی (ساعت اختیاری) | `1405/07/10 18:30` · `2026-10-02 18:30` |

اعداد فارسی هم قبول می‌شوند. هر چه بعد از زمان بیاید متن پیام است و شمارش زیر آن می‌آید.
برای گذاشتن شمارش وسط متن از `{}` استفاده کنید:

```
@DrNetTimerBot 3d تا انتشار {} مانده
```

## تنظیمات

در `wrangler.toml` (بعد از تغییر: `npm run deploy`):

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `TZ_OFFSET` | `+03:30` | منطقهٔ زمانی برای ورودی ساعت و تاریخ |

Secretها را `npm run setup` می‌سازد: `BOT_TOKEN`، `WEBHOOK_SECRET` و `ALLOWED_USERS` (اختیاری).

## محدودیت‌ها

- تلگرام خودش متن پیام را زنده نمی‌کند و ویرایش ثانیه‌به‌ثانیه هم به flood limit می‌خورد.
  برای همین پیام تا دقیقه دقیق است و دقیقه‌ای یک بار ویرایش می‌شود. دکمهٔ «⏱ زمان دقیق» زمان را تا ثانیه
  نشان می‌دهد.
- هزینه: هر شمارش فعال روزانه حدود ۱٬۴۴۰ درخواست Durable Object مصرف می‌کند. سقف پلن رایگان ۱۰۰٬۰۰۰
  درخواست در روز است، یعنی حدود ۶۹ شمارش همزمان.
